# 🫀 CardioCoin  
## نظام ذكي لمراقبة صحة القلب وكشف السقوط باستخدام الذكاء الاصطناعي

CardioCoin هو نظام متكامل يعتمد على الذكاء الاصطناعي لمراقبة نبض القلب وحركة الجسم بشكل لحظي، مع القدرة على اكتشاف السقوط أو اضطراب النبض، ثم إرسال رسالة طوارئ فورية عبر منصة نهى 2.0 (LLM) لضمان سرعة الاستجابة ودقة التشخيص.

1) تحليل نبض القلب والحركة معًا  
يستخدم النظام نموذج **CNN-LSTM** لتحليل الإشارات الحيوية (النبض + الحركة) وتصنيف حالة المستخدم بدقة.

2) اكتشاف الشذوذ الحيوي  
يتم استخدام **Autoencoder** لاكتشاف أي خلل مفاجئ في الإشارات الحيوية.

3) معايير أمان ديناميكية حسب العمر  
يقوم النظام بتغيير عتبات النبض تلقائيًا حسب الفئة العمرية:
- طفل  
- بالغ  
- مسن  

4) التكامل مع منصة علم – نهى 2.0  
عند اكتشاف خطر، يتم إرسال البيانات إلى نموذج لغوي كبير (LLM) لصياغة رسالة طوارئ قصيرة ودقيقة.
طريقة التشغيل

1-افتح الملف: 
CardioCoin_4.py 
2 -من القائمة العلوية اختر:
Runtime → Run all
3- سيقوم النظام تلقائيًا بـ:
- تحميل المكتبات الأساسية  
- تفعيل دالة تحديد عتبات النبض حسب العمر  
- بناء نموذج CNN-LSTM  
- بناء Autoencoder  
- تدريب النماذج  
- تشغيل النظام باستخدام:
  ```
  run_cardio_coin_system()
  ```
