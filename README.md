# CardioCoin-Project
مشروع CardioCoin: نظام ذكي لمراقبة صحة القلب وكشف السقوط باستخدام AI. يحلل النبض والحركة معاً، ويغير معايير الأمان تلقائياً حسب عمر المستخدم (طفل/بالغ/مسن). يتكامل النظام مع "نهى 2.0" (LLM) لصياغة رسائل استغاثة فورية للمسعفين عند الطوارئ، مما يضمن سرعة الاستجابة ودقة التشخيص الطبي.
